03 · Projects

Featured Project

RASSAD

DistilRoBERTa NLP Text Classification Explainable AI Python

An AI-based system designed to monitor text for compliance with Saudi Arabia's Personal Data Protection Law (PDPL). It combines NLP and DistilRoBERTa-based text classification with rule-based compliance checks, predictive analysis, explainable AI, and automated recommendations to help assess potential privacy violations and support compliance review.

Power BI Power Query DAX Data Modeling

An interactive Power BI dashboard analyzing U.S. air quality trends and AQI patterns from 2020, covering seasonal comparisons between coastal and inland states, monthly AQI trends, pollutant concentration by state, and the relationship between pollutant levels and AQI, drawing on data from more than 4,000 monitoring stations.

Flower Classification — Custom CNN

A deep learning project that uses a custom Convolutional Neural Network (CNN) built with TensorFlow and Keras to classify flower images into multiple categories.
